You Might Not Need an Effect

Type in either box and compare the render counters. Copying props into state with an effect costs an extra render every time.

✅ If a value can be calculated from props or state, calculate it during render. Effects are for synchronising with things outside React (network, timers, the DOM), not for values you can work out yourself.

React version (from the slides)

import { useState, useEffect, useRef } from 'react';

// Unnecessary effect: extra state and an extra render
function WithEffect({ first, last }) {
  const renders = useRef(0); renders.current += 1;   // demo counter only
  const [fullName, setFullName] = useState('');
  useEffect(() => { setFullName(first + ' ' + last); }, [first, last]);
  return <p>WithEffect: {fullName} (renders: {renders.current})</p>;
}

// Better: derive the value while rendering
function Derived({ first, last }) {
  const renders = useRef(0); renders.current += 1;   // demo counter only
  const fullName = first + ' ' + last;
  return <p>Derived: {fullName} (renders: {renders.current})</p>;
}
