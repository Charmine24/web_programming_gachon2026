TODO 3: on mount, an effect asks the browser for the user’s location and uses it for the first weather request. If the user says no, it falls back to Seoul.

⚠️ The browser asks permission first. Geolocation only works on HTTPS pages (GitHub Pages is HTTPS) or on localhost. The cleanup sets a flag so a late answer is ignored if the component has already unmounted.

React version (my solution)

useEffect(() => {
  let cancelled = false;
  if (!('geolocation' in navigator)) { setCoords(SEOUL); setNote('Geolocation not supported'); return; }

  navigator.geolocation.getCurrentPosition(
    pos => { if (!cancelled) setCoords({ name: 'Your location',
                                         latitude: pos.coords.latitude,
                                         longitude: pos.coords.longitude }); },
    err => { if (!cancelled) { setCoords(SEOUL); setNote(err.message); } },
    { timeout: 10000 }
  );
  return () => { cancelled = true; };   // ignore a late answer after unmount
}, []);                                  // [] = ask once, on mount
