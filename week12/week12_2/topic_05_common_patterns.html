Common Patterns

Three patterns you will use again and again: syncing the document title, debouncing a search, and mapping class lifecycle methods to useEffect.

Pattern 1: sync the document title with state

Look at this browser tab's title while you click.

useEffect(() => {
  document.title = `${unreadCount} unread messages — WebPro`;
}, [unreadCount]);

Pattern 2: debounced search

Type a fruit name quickly. The request only goes out once you stop typing for 400ms (simulated search API).

const [query, setQuery] = useState('');
const [results, setResults] = useState([]);

useEffect(() => {
  if (!query) { setResults([]); return; }

  const timerId = setTimeout(async () => {
    const res  = await fetch(`/api/search?q=${query}`);
    const data = await res.json();
    setResults(data);
  }, 400); // wait 400ms after typing stops

  return () => clearTimeout(timerId); // cancel if query changes quickly
}, [query]);
