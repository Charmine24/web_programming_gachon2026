useEffect Syntax & Dependency Array

useEffect takes a function (the effect) and an optional dependency array. The array controls WHEN the effect runs.

import { useState, useEffect } from 'react';

useEffect(
  () => {
    // Effect code runs here (after render)
    console.log('Effect ran!');

    // Optional: return a cleanup function
    return () => {
      console.log('Cleanup!');
    };
  },
  [dep1, dep2]  // ← dependency array
);
Dependency arrayWhen does the effect run?
useEffect(fn): no arrayAfter every render (avoid, usually wrong)
useEffect(fn, []): empty arrayOnce, after the first render (like componentDidMount)
useEffect(fn, [a, b])After the first render, and whenever a or b changes

One component has state a and b and four effects. Change things and watch which counters go up.

⚠️ Infinite loop trap: if an effect updates a state variable that is also in its own dependency array, the effect runs again after every update, forever. Always ask: "does updating this state make my effect run again?"
