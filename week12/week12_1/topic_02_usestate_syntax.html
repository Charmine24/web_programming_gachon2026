useState Syntax

const [value, setValue] = useState(initialValue);
  • useState returns [currentValue, setterFunction].
  • The argument is the initial value, used only on the first render.

⚠️ Rules of Hooks: never call useState inside loops, conditions, or nested functions. Call hooks at the top level of the component, in the same order every render.
