Updating State — Rules

Rule 1: Never mutate state directly — always call the setter
  ❌ count++;  state.name = 'Amir';  items.push('new item');
  ✅ setCount(count + 1);  setName('Amir');  setItems([...items, 'new item']);
Rule 2: Objects — spread to copy first, then override what changed
Rule 3: Arrays — use non-mutating methods (spread, filter, map)
Functional updates: when new state depends on the previous state,
  use the callback form so you always get the LATEST value.
