What changed

The portfolio remains a static HTML, CSS, and JavaScript site, so these concepts are implemented with framework-free JavaScript rather than adding a React build step.

1. State and event-driven updates

The project explorer stores the active tab, search query, and selected skill in one state object. User actions update that state and re-render the visible interface.

2. Functional components and props

createTagButton(tag, selected) is a reusable component-like function. Its parameters act like props, producing consistently configured filter buttons.

3. List rendering

Skill filters are derived from the existing card data and rendered from a unique, sorted list, similar to React's .map() pattern.

4. Conditional rendering

The explorer shows only the active tab, hides cards that do not match, and creates an empty-state message when no work matches the current filters.

5. Component composition

The explorer combines tabs, a search control, skill filters, status text, cards, and an empty state, each handled by a focused part of the render flow.

6. Files changed

index.html adds the explorer interface and navigation link. js/main.js adds the state and rendering logic. css/style.css styles the controls and empty state.
